# 🍰 Bakery Sales Analysis Dashboard

An interactive **Power BI dashboard** developed to analyze bakery sales data and transform raw business data into meaningful insights that support data-driven decision-making.

---

## 📖 Project Overview

This project demonstrates how Business Intelligence can be used to monitor sales performance, identify customer trends, evaluate product performance, and provide actionable insights for business growth.

The dashboard enables users to explore sales data through interactive visualizations, helping business owners make informed decisions based on real-time analytics.

---

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-selling products
- Track revenue trends
- Understand customer purchasing behavior
- Generate business insights using interactive dashboards
